# Altcoin Arbitrage Trading System

Автоматизированная система арбитражной торговли альткоинами между криптовалютными биржами.

## Особенности

### Автоматическое обнаружение возможностей
- **Автоматический поиск пар**: Система автоматически анализирует все доступные торговые пары на всех подключённых биржах
- **Проверка сетей**: Автоматическое определение совместимых сетей для перевода между биржами
- **Без конфигурации пар**: Не требуется ручная настройка торговых пар

### Проверка возможности вывода/депозита
- ✅ Статус вывода на бирже-источнике (включен/выключен)
- ✅ Статус депозита на целевой бирже
- ✅ Совместимость сетей (ERC-20, BEP-20, TRC-20 и др.)
- ✅ Минимальные суммы для вывода/депозита
- ✅ Комиссии за вывод

### Анализ ликвидности
- 📊 Глубокий анализ стаканов ордеров (order book)
- 📊 Расчёт проскальзывания для заданного объёма
- 📊 Проверка доступного объёма для покупки/продажи
- 📊 Определение максимально исполнимого объёма

### Расчёт прибыльности
Учитываются все комиссии:
- 💰 Торговые комиссии (maker/taker) на обеих биржах
- 💰 Комиссия за вывод
- 💰 Сетевые комиссии (если применимо)
- 💰 Комиссия за депозит (редко, но проверяется)

### Управление рисками
- ⚠️ Оценка времени перевода
- ⚠️ Анализ волатильности
- ⚠️ Проверка ликвидности
- ⚠️ Оценка риска проскальзывания
- ⚠️ Статус сети/обслуживания
- ⚠️ Общий риск-скор для каждой возможности

## Установка

```bash
# Клонирование репозитория
cd altcoin-arbitrage

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env и добавьте API ключи бирж
```

## Конфигурация

### Переменные окружения (.env)

```env
# Binance
BINANCE_API_KEY=your_api_key
BINANCE_API_SECRET=your_api_secret

# Bybit
BYBIT_API_KEY=your_api_key
BYBIT_API_SECRET=your_api_secret

# Другие биржи...
```

### Параметры риска (config/settings.py)

```python
class RiskSettings:
    max_position_size_usd = 1000       # Макс. размер позиции в USD
    min_profit_threshold_percent = 0.5  # Мин. порог прибыли %
    max_transfer_time_minutes = 30      # Макс. время перевода
    max_price_slippage_percent = 0.3    # Макс. проскальзывание %
    min_liquidity_multiplier = 3        # Мин. глубина стакана = 3x объёма
```

## Использование

### Разовый скан возможностей

```bash
python main.py scan
```

### Обнаружение арбитражных активов

```bash
python main.py discover
```

### Непрерывный мониторинг (dry-run)

```bash
python main.py monitor --dry-run
```

### Непрерывный мониторинг с кастомными параметрами

```bash
python main.py monitor \
    --exchanges binance,bybit,okx \
    --min-profit 1.0 \
    --max-position 500 \
    --interval 15
```

### Реальная торговля (ОСТОРОЖНО!)

```bash
python main.py monitor --live
```

## Риски и предупреждения

⚠️ **ВНИМАНИЕ**: Арбитражная торговля сопряжена с рисками!

### Основные риски:

1. **Волатильность цены** - цена может измениться пока средства в пути
2. **Задержки сети** - перегруженность блокчейна может увеличить время перевода
3. **Приостановка вывода** - биржа может внезапно остановить вывод
4. **Недостаточная ликвидность** - может не хватить объёма в стакане
5. **Технические сбои** - API бирж могут быть недоступны

### Рекомендации:

- 🔴 Начинайте только с режима dry-run
- 🔴 Используйте только те средства, потерю которых можете позволить
- 🔴 Установите строгие лимиты на размер позиции
- 🔴 Мониторьте работу системы постоянно
- 🔴 Проверьте API ключи - им нужны разрешения на торговлю и вывод
